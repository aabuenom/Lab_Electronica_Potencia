# Laboratorio de Electrónica de Potencia
 Códigos y Programas del Laboratorio de Electrónica de Potencia USB
 En este repositorio se incluyen las guías de laboratorio, y los códigos de arduino y python para las diferentes actividades.
 
## Maquetas
 
 1. Móvil de dos (2) ejes con servomotor
 ![Movil 2 Ejes](imagenes/soporte-pan-tilt-para-servo-sg90-mg90.jpg  "Movil 2 Ejes")
 2. Brazo Mecánico con tres ejes de libertad con servomotores
 ![Brazo 3 ejes](imagenes/Brazo.png  "Brazo 3 ejes")
 3. Inversores Monofásicos
 	- Onda Cuadrada
 	- Modulación Unipolar
 	- Modulación Bipolar
 4. Inversores Trifásicos
 	- Onda Cuadrada
 	- Modulación
 5. Troceadores o Chopper
 6. Rectificador
 	- Media Onda Controlado
 	- Monofásico con transformador de toma central
 	- Trifásico de Media Onda
 7. Controlador AC-AC
 	- Control de Fase
  	- Control Integral
 8. Cicloconvertidor de Medio Punto
 
Estos son los códigos de programación de los arduinos para la Práctica 6
